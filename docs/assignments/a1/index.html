Problem Statement

Compare image classification models on Fashion-MNIST: Linear / Softmax, MLP, CNN, LSTM or GRU, and Transformer.

Dataset Description and EDA

Use the official Fashion-MNIST test set. Split the official training set into training and validation with a fixed seed. EDA will be added after analysis.

Methodology

The Linear classifier flattens each image and produces raw class logits. Other model families remain TODO.

Experimental Setup

Default configuration: seed 42, 10% validation split, batch size 64, Adam, learning rate 0.001, 10 epochs. Normalize with fixed mean 0.5 and standard deviation 0.5. These are configuration defaults, not completed experiments.
