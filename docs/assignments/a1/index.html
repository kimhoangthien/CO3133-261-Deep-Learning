Problem Statement

Compare image classification models on Fashion-MNIST: Linear / Softmax, MLP, CNN, LSTM or GRU, and Transformer.

Dataset Description and EDA

Fashion-MNIST uses 54,000 training, 6,000 validation and 10,000 official test images with seed 42. The local integration review executed all 11 EDA code cells without errors: training classes contain 5,353–5,445 images, validation classes 555–647, and test classes exactly 1,000 each. Images have shape [1, 28, 28] and normalize to [-1, 1]. The executed notebook and figures are local ignored artifacts; findings still need incorporation into the submitted notebook/report.

Methodology

Linear flattens each image into 784 features and maps them to ten raw logits. MLP uses 784 → 128 → 10 with ReLU after the hidden layer and no dropout. Both use the shared trainer/evaluator. CNN, LSTM/GRU and Transformer remain TODO.

Experimental Setup

Default configuration: seed 42, 10% validation split, batch size 64, Adam, learning rate 0.001, 10 epochs. Normalize with fixed mean 0.5 and standard deviation 0.5. Both recorded full-data CPU runs used this protocol for ten epochs with no sample limit, identical split hashes, and checkpoint selection by best validation accuracy (epoch 10 for both).
